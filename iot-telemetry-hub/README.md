# IoT Telemetry Hub

Микросервис на Go для сбора и парсинга потоковых данных (телеметрии) с edge-устройств (камер транспортной безопасности и дорожных датчиков).

## Архитектура и особенности проекта:
- **Потоковая обработка (Stream Processing):** Чтение данных с эмулятора датчиков через интерфейс `io.Reader` порциями фиксированного размера. Сервис работает по принципу конвейера и оптимизирован по памяти (эффективное использование оперативной памяти без полной выгрузки больших массивов данных).
- **Чистая архитектура (Clean Architecture):** Код разделен на независимые слои (симулятор, парсер потока, хранилище), организованные по стандарту Standard Go Project Layout.

## Технологический стек:
- **Язык:** Go (Golang)
- **База данных:** Sqlite
- **Инструменты:** Docker, Пакеты `io`, `bufio`, `bytes`

## Статус разработки:
-  Этап 1: Разработка бинарного протокола и эмулятора датчика (`io.Reader`)
-  Этап 2: Создание конвейера парсинга потока байт
-  Этап 3: Интеграция с Sqlite и сохранение телеметрии
-  Этап 4: Контейнеризация сервиса (Docker)
