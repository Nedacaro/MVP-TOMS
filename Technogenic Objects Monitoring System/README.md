                                        Мониторинг техногенных объектов
    Описание проекта

Приложение для мониторинга и анализа состояния техногенных объектов на основе данных из SQLite базы данных. Программа позволяет загружать данные, вычислять ключевые параметры (μ - длина вектора, α - угол поворота), строить прогнозы и визуализировать результаты в удобном графическом интерфейсе.

    Основные функции
1. Управление данными

    Загрузка данных из SQLite базы данных

    Добавление/удаление строк (эпох)

    Редактирование значений ячеек

    Поддержка формата CSV с разделителем запятой

2. Расчет параметров

    μ (мю) - длина вектора (общая интенсивность параметров)

    α (альфа) - угол поворота (структурное изменение)

    Автоматический расчет при загрузке данных

3. Прогнозирование

    Экспоненциальное сглаживание с коэффициентами α = 0.1, 0.4, 0.7, 0.9

    Прогноз для всех точек и отдельных параметров

    Визуализация прогнозных значений на графиках

4. Анализ состояния

    Расчет статуса объекта на основе сравнения L и R

    Норма (зеленый): L < R

    Предаварийное (оранжевый): L ≈ R

    Авария (красный): L > R

5. Групповой анализ

    Разделение точек на блоки А и Б

    Расчет параметров для блоков

    Сравнительный анализ блоков

6. Визуализация

    Графики прогнозных значений

    Функция отклика S(t)

    Фазовые траектории

    Таблицы с цветовой индикацией статусов

    Отображение изображения объекта мониторинга
